### 🚀 What I build

- 🔐 **Crypto wallets & custody**: hot/cold wallets, KMS-signed withdrawals, deposit detection and sweeps across **TRON, BNB Smart Chain and Polygon**
- 📒 **Money-safe ledgers**: idempotent double-entry ledger, timelocked high-value withdrawals, per-chain outflow limits
- ⚙️ **Backend systems**: Go microservices on PostgreSQL, Kafka and Redis, with zero-downtime deploys on AWS
- 📱 **Mobile**: 20+ production Android and Flutter apps, 50K+ Play Store downloads
- 🤖 **AI**: RAG and agentic systems on AWS Bedrock and ChromaDB
